# 기준선 전의 마이그레이션 (시험 자료)

첫 배포 전에 trpg-server 의 마이그레이션 172개를 기준선 하나(`migrations/versions/*_baseline.py`)로 합쳤다(#1273).
이 폴더는 그 전의 마이그레이션 파일들이다. alembic 은 이 폴더를 읽지 않는다. 적용하는 사슬에 들지 않는다.

남겨 둔 까닭은 시험이다. 옛 판을 지금 형식으로 올려 읽는 시험(`app/assets/scenarios/upgrades.py`)이
옛 마이그레이션이 채운 규칙의 값으로 옛 판을 만들고, 몇몇 시험은 옛 룰북을 고치던 함수를 그대로 돌려 본다.
시험이 `load_migration` 으로 파일 하나씩 불러 쓴다.

- 새 마이그레이션은 여기가 아니라 `migrations/versions/` 에 만든다.
- 여기의 파일은 고치지 않는다. 옛 판이 그때의 값으로 읽히는지를 보는 자료다.
- 옛 판을 올려 읽는 코드(`upgrades.py`)를 정리할 때 이 폴더도 함께 정리한다.
