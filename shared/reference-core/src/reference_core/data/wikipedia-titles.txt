# 위키백과에서 받을 문서의 제목 목록(reference_core/wiki_titles.py). 첫 판이다. 고르고 고쳐 쓴다.
# 한 줄에: 한국어 제목 | 영어 제목 | 다른 이름, 다른 이름
#   - 한국어판에 그 제목의 문서가 있으면 그것을 받는다. 없거나 동음이의어 문서면 영어 제목으로 영어판에서 받는다
#   - 다른 이름은 장면에서 그 낱말이 나오면 고르는 이름이다(다섯까지, 30자). 한국어 제목(괄호를 뗀 것)이 맨 앞에 붙는다
#   - 받는 명령이 없거나 쓸 것이 없던 제목을 알린다. 그 줄은 고치거나 지운다
# 고르는 기준: 판타지와 근대 이전의 장면에서 생김새와 쓰임을 채울 사물, 생물, 건축, 지형. 사람과 사건과 나라는 넣지 않는다.
