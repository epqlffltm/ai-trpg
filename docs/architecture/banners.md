# 홍보 배너

첫 화면 위쪽의 넘기는 배너(#994). 운영자가 사이트 안의 작품(TRPG 시나리오, chat 캐릭터, story 세계관)을 골라 건다.
제작자가 돈을 내고 거는 홍보는 아직 없다.

## 누가 가지는가

작품의 서버마다 따로 가진다.

| 작품 | 서버 | 테이블 |
| --- | --- | --- |
| TRPG 시나리오 | trpg-server | `banners`(`scenario_id` → `scenarios`) |
| chat 캐릭터, story 세계관 | asset-server | `banners`(`character_id` 또는 `world_id` 가운데 하나) |

한 곳에 모으지 않는 까닭: 배너는 읽을 때마다 "그 작품이 지금 공개 목록에 나오는가"를 본다.
그것을 아는 것은 작품의 서버다. 한 곳에 두면 그 서버가 실행 중에 다른 서버를 불러야 한다([공용 코드 규칙의 원칙 2](shared-code.md#원칙)).
화면은 두 서버를 따로 부르고 서비스 차례(TRPG, chat, story)로 잇는다. 서버 사이에 섞어 정렬하지 않는다(#593).

## 보이는 것

배너에 따로 그림과 글을 두지 않는다. 작품의 공개 정보를 그대로 보인다(시나리오는 제목과 한줄소개, 캐릭터와 세계관은 마지막 판의 이름, 대표 그림, 태그).

보이는 조건은 둘 다다.

- 기간 안이다: `starts_at <= 지금 < ends_at`. `ends_at` 이 비어 있으면 내릴 때까지다
- 작품이 공개 목록의 조건에 맞는다: 공개 중(시나리오는 공개한 판이 있다, 캐릭터와 세계관은 공개이고 게시한 판이 있다), 링크로만 여는 것이 아니고(#993), 지우지 않았고 숨기지 않았고, 보는 사람이 볼 수 있는 등급이다(로그인 전과 성인 확인 전에는 전체 이용가만)

공개 목록처럼 보는 사람의 설정으로도 거른다. `hide_adult=true` 면 성인용이 빠지고(#986), `orientation` 을 주면 그 태그가 붙은 것만이다(#987).
화면이 인증 서버의 내 정보에서 읽어 싣는다. 배너의 서버는 인증 서버를 부르지 않는다.

공개를 내리거나 숨기면 배너는 남지만 보이지 않는다. 다시 공개하면 기간 안이면 다시 보인다. 작품의 행을 지우면 배너도 지워진다(외래 키의 CASCADE).
시나리오는 지워도 행이 남아(지운 시각만 적는다) 배너가 남고 보이지 않는다.

차례는 `position`(0~999, 작은 것이 먼저), 같으면 먼저 건 것이 먼저다. 서버 안에서만 쓰는 차례다.

## API

| 메서드 | 주소 | 하는 일 | 누가 |
| --- | --- | --- | --- |
| GET | `/api/v1/game/banners`, `/api/v1/asset/banners` | 지금 걸린 배너. 차례대로. `hide_adult`, `orientation`(공개 목록과 같다) | 누구나(로그인하지 않아도 된다) |
| GET | `/api/v1/game/admin/banners`, `/api/v1/asset/admin/banners` | 모든 배너(지난 것까지)와 지금 보이는지(`shown`) | 운영자 |
| POST | 같은 주소 | 배너를 건다. 시나리오는 `{scenario_id, position?, starts_at?, ends_at?}`, asset 은 `{kind, target_id, position?, starts_at?, ends_at?}`. 공개 목록에 나오는 작품이 아니면 409 `not_published` | 운영자 |
| PATCH | `…/admin/banners/{id}` | 차례와 기간을 고친다. `ends_at: null` 이면 내릴 때까지 | 운영자 |
| DELETE | `…/admin/banners/{id}` | 내린다(지운다). 204 | 운영자 |

운영자가 아니면 운영자의 주소는 404 다(주소가 있다는 것을 알리지 않는다). 시각은 시간대가 붙은 값만 받는다.
배너를 걸고 내리는 일은 운영자의 감사 기록(`operator_actions`)에 남기지 않는다. 남의 것을 제재하는 일이 아니다.

## 화면

- 첫 화면(A1)의 맨 위. 걸린 것이 없으면 아무것도 보이지 않는다. 한 장씩, 이전·다음 단추로 넘긴다(저절로 넘기지 않는다). 누르면 작품의 소개로 간다
- 운영자의 "배너"(`/operator/banners`, 머리의 메뉴). 종류와 작품 ID, 차례, 기간으로 걸고, 목록에서 내린다. 차례와 기간을 고치는 칸은 아직 없다(API 는 있다)

## 알아 둘 것

- 배너는 공개 목록의 조건을 그대로 쓴다(asset 은 `listed`, 시나리오는 `visible`, `listed`, `filtered`). 공개 목록의 조건이 바뀌면 배너도 함께 바뀐다
